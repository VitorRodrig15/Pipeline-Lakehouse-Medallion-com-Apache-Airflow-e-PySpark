# Pipeline-Lakehouse-Medallion-com-Apache-Airflow-e-PySpark
Este projeto implementa uma pipeline de dados em arquitetura Medallion (Landing, Bronze, Silver e Gold) para processamento distribuído de dados de e-commerce. A orquestração das tarefas é realizada pelo Apache Airflow via Docker, utilizando PySpark para ingestão, tratamento e agregação dos dados.
